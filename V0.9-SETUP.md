# v0.9 setup and release checklist

1. Create `apps/api/.venv` and install `python -m pip install -e ".[dev]"` using that interpreter.
2. In `apps/web`, run `npm ci` (the verified lockfile is included).
3. Run backend `python -m pytest -q` using the venv interpreter.
4. Run `npm run check`, `npx playwright install chromium`, and `npm run test:e2e` from `apps/web`.
5. Check `npm audit`, review `git diff`, and push to GitHub.
6. Confirm both GitHub Actions workflows pass on the actual repository. Do not claim CI success before observing it.

On Windows, Playwright finds `apps/api/.venv/Scripts/python.exe` without activation. On Linux/macOS, it finds `apps/api/.venv/bin/python`. CI uses the Python interpreter installed by GitHub Actions. Both browser journeys use one worker.

The approved homepage and bilingual challenge were not changed in this packaging revision. The previous v0.8 test evidence does not establish that v0.9 changes passed until rerun.
